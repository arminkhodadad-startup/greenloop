# GreenLoop — GitHub Pages MVP

GreenLoop is an AI-powered smart city and citizen rewards platform.

## Included

- `index.html` — startup landing page
- `app.html` — citizen mobile MVP
- `dashboard.html` — responsive municipal desktop MVP
- `assets/` — logo and favicon

## Publish on GitHub Pages

1. Create a new public repository named `greenloop`.
2. Upload **the contents of this folder**, not the ZIP itself.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`.
6. Save. GitHub will provide a URL similar to:
   `https://YOUR-USERNAME.github.io/greenloop/`

## Demo links after deployment

- Landing page: `/greenloop/`
- Citizen MVP: `/greenloop/app/`
- Municipal dashboard: `/greenloop/dashboard/`

All data is demo/seed data. No API keys or server are required.
